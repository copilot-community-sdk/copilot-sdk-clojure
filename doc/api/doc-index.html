The native decision defines the current scope. Earlier decisions in doc/adr/ record why 1.x worked as it did; they are not transport or feature promises for 2.x. See the 1.x documentation at its source revision for those APIs and the historical benchmark evidence for that implementation. No 2.x performance comparison follows from those measurements.

In test/resources/, native_2_0_1_contracts.edn is the frozen upstream and preview inventory. native_2_0_1_rc_overlay.edn maps that inventory to the candidate’s source, tests, and outstanding gaps. A mapped symbol or a passing example is not a certificate of complete upstream parity.
