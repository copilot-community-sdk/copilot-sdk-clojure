copilot.sdk

Clojure client for the in-process Copilot runtime. Exchange immutable data over core.async channels. Resource acquisition and close block the caller.

abort!

(abort! session)

Ask the runtime to abort active work on the session. The result channel delivers {:ok nil} on acknowledgment or {:error cause} on failure.

approve-all

(approve-all request invocation)

Explicit permission handler for trusted, unmanaged use only. Abstains when the runtime requires managed approval; never enabled by default.

auth-status

(auth-status client)

Return the runtime’s authentication status on a channel. This does not sign in or grant access.

await!!

(await!! result)

Block for one operation result. Return its value (including nil) or throw its error. If interruption withdraws the take, throw InterruptedException with the flag cleared. You can await the same operation again. If the take already claimed the result, deliver it and preserve the interrupt status. Inside a go block, use <! and inspect the result instead.

close!!

(close!! resource)

Detach a session without deleting history, or shut down an owned client. May block or throw; never call from a go block.

delete-session!!

(delete-session!! client id)

Delete a saved session from the client’s default runtime store. Confirm its unique, exact ID with the runtime’s listing before sending the delete. Refuse UUID prefixes, unlisted IDs (:session-delete-unconfirmed), and handles using another storage root. Refusal leaves the session’s files intact. Acknowledgment invalidates the matching open handle. For application-owned storage, delete through the filesystem provider after closing the session.

elicit!

(elicit! session form)

Ask a capable host for structured input using :message and :requested-schema. The result contains :action (:accept, :decline or :cancel) and optional :content and :_meta maps with the host’s original JSON member names. The schema’s property names belong to the application. The request waits for a response or for the session to close; it has no SDK timer for human input. A client can have 64 unanswered outbound forms. An excess request returns :elicitation-capacity without sending a form.

force-close!!

(force-close!! client)

Release an owned client without waiting for runtime detach/shutdown RPCs. Still waits for the native callback safety barrier; never unloads live code.

history

(history session)(history session view)

Return normalized session events, or their original JSON values with :raw. Raw history has string keys, original timestamps and exact integers.

last-session-id

(last-session-id client)

Return a result channel for the most recently updated session ID, or nil if none.

lifecycle-events

(lifecycle-events client)

Subscribe to runtime-reported client lifecycle events. Close the channel to unsubscribe; this does not detach any session.

list-models

(list-models client)

Read available models. Concurrent calls share a cache owned by this native client; a failed lookup is not cached.

list-sessions

(list-sessions client)(list-sessions client filters)

Return a channel of session metadata. Optional filters use :cwd, :git-root, :repository and :branch.

log!

(log! session message)(log! session message options)

Append a session timeline entry. Optional :level is :info, :warning or :error; :ephemeral? omits it from saved history.

mcp-tool-result

(mcp-tool-result result)

Convert an MCP call result to a map that a tool handler can return. Supply a :content vector of blocks with string :type values (“text”, “image”, or “resource”). Set :is-error? to true for a failed call. Text is joined with newlines. Image :data and resource :blob must be canonical Base64. A resource blob without a :mime-type uses application/octet-stream; its :uri becomes the binary description.

open-client!!

(open-client!! options)

Load the pinned runtime in this JVM and negotiate SDK protocol 4. Select :mode :coding-agent or :empty. In empty mode supply isolated storage. Prefer with-client when the lifetime fits a lexical scope.

open-session!!

(open-session!! client options)

Create an owned session using grouped 2.x options. In :empty client mode supply an explicit :tools :available-tools allowlist, possibly [].

ping

(ping client)(ping client message)

Round-trip a control request to this client’s runtime. Does not call a model.

respond!!

(respond!! session kind answer)

Settle a pending :tool or :permission request. Pass :request-id and :result (or :error for a failed tool). After submission, wait for the bounded outcome even if interrupted, and preserve the interrupt status.

resume-session!!

(resume-session!! client session-id options)

Open a new handle to a saved session. Supply live callbacks and provider configuration again; saved model identity is not a credential registry. New permission requests can be answered with respond!! without a handler. To continue pending work, pass :continue-pending-work? true and retain the original request ID; the runtime does not re-emit pending permissions.

send!

(send! session message)

Submit a message. The channel delivers {:ok message-id} or {:error cause}, then closes. Submission is not turn completion.

send-and-wait!!

(send-and-wait!! session message)

Start one turn and block the calling thread for its final assistant event (or nil for an ordinary turn with no reply). Throws on error or timeout. Takes the same message and deadline as start-turn!. Check for interruption at submission. If interruption withdraws the take, abandon this wait and throw InterruptedException with the flag set. Do not abort or resend. Inside go, take an already-started result with <! instead of blocking.

session-id

(session-id session)

Return the session ID that can be passed to resume-session!!.

session-info

(session-info session)

Read the session ID and :capabilities (nil until reported). The workspace path, transcript recovery and permission mode result appear only if reported.

session-metadata

(session-metadata client id)

Read metadata for one saved session on a result channel, or {:ok nil} when it is absent. Times are Instants; optional client names are retained.

set-model!

(set-model! session model)(set-model! session model tuning)

Ask the runtime to switch the active model. Optional tuning applies only to this selection; it does not replace provider connections.

start-turn!

(start-turn! session message)

Start one turn from a prompt string or message map. Return a one-shot result channel without waiting for the answer: {:ok event} for this request’s final root assistant message, {:ok nil} for an ordinary turn with no reply, or {:error cause}. This is not a stream of progress events. :timeout-ms defaults to 60000. Close the channel if you abandon the wait: this can withdraw a prompt the writer has not claimed, but does not abort a turn already sent to the runtime.

status

(status client)

Return the loaded runtime’s version and negotiated SDK protocol version.

subscribe

(subscribe session)

Observe events from the whole session, including other turns. Use a turn’s own result for its final reply. Close the subscription when done; this does not abort work or detach the session.

with-client

macro

(with-client [binding options] & body)

Bind an open native client for the body, then shut it down. A body failure remains primary if shutdown also fails.

with-resumed-session

macro

(with-resumed-session [binding client id options] & body)

Bind a resumed session for the body, then detach it. A body failure remains primary if detach also fails.

with-session

macro

(with-session [binding client options] & body)

Bind a new session for the body, then detach it. Finish or cancel any asynchronous work that owns this session before the body returns.
