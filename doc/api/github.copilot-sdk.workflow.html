Read the latest durable envelope for a workflow run.

get-run-detail

(get-run-detail session run-id)

Read durable phases, agents, and recent progress for a run.

get-run-progress

(get-run-progress session run-id)(get-run-progress session run-id options)

Page durable progress for a workflow run.

Options: :phase-id, :after-seq, :before-seq, and :limit (1-500). Cursors are exclusive. Returns :records, :oldest-seq, :newest-seq, :has-more-older, :has-more-newer, and :revision.

json-null

Sentinel for an explicit JSON null workflow result. A nil run result means no result.

list-runs

(list-runs session)

Return the runtime’s newest default page of this session’s workflow runs.

resume!

(resume! session run-id)(resume! session run-id {:keys [limits], :as options})

Resume a durable workflow run and return its terminal envelope.

In :limits, omission preserves a ceiling and nil explicitly removes it.

run!

(run! session name-or-handle)(run! session name-or-handle {:keys [args limits resume-from-run-id], :as options})

Run a registered workflow by name or handle and return its terminal envelope.

In :limits, omission preserves a ceiling and nil explicitly removes it.

terminal-status?

(terminal-status? status)

Return true when a workflow attempt has settled, including a paused attempt.

wait-for-run!

(wait-for-run! session run-id)(wait-for-run! session run-id {:keys [cancel-chan poll-interval-ms], :or {poll-interval-ms 5000}})

Wait until a workflow run reaches a terminal status.

Options: - :cancel-chan channel whose close/value aborts the wait, not the run - :poll-interval-ms polling safety-net interval (default 5000)

workflow-handle?

(workflow-handle? value)

Return true when value is a workflow handle created by define-workflow.
