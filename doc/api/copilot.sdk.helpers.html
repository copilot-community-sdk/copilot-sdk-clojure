copilot.sdk.helpers

Blocking queries and lexical scopes for native Copilot conversations.

decode-json

(decode-json text)

Decode one complete JSON value. Preserve object keys as strings, integers without rounding, and decimals as BigDecimals. JSON false and null return false and nil. Arrays and objects may nest up to 128 levels in total. Invalid input throws without including the response text.

query!!

(query!! session message)

Send one message on a borrowed session. Block for its final assistant text, or nil if there was no text. Errors propagate without a retry.

query-json!!

(query-json!! session message)

Send one message with a :prompt and explicit :response-schema map on a borrowed session. Decode its final text on the calling thread. The schema requests structured output; validate the decoded value in the application.

query-once!!

(query-once!! config message)

Open a conversation, send one message, and return its text or nil. Supply the same explicit config as with-conversation.

with-conversation

macro

(with-conversation [session config] & body)

Open one client and one session from the explicit :client and :session option maps in config. Bind the session for the body, then detach it and shut down the client. Do not return work that still needs these resources.

with-subscription

macro

(with-subscription [events session] & body)

Bind a subscription to events from the whole session. Close only this subscription on exit. A body failure remains primary if close fails.
